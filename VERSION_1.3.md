# LiraSlabZones 1.3.0 — 30.10.2026

Версия продолжает ветку 1.2 от коммита `4941bc4`. Цель — ускорить полный
пересчёт, сохранив результат раскладки и все проверки допустимости.

## Изменения

- Проверки покрытия КЭ используют индекс зон, подготовленный один раз на
  неизменяемый проход. Входной порядок, фильтр As, максимальный шаг подходящих
  зон и DesignEdgeCoverMm сохраняются. После изменения раскладки индекс
  создаётся заново. Обычный полный перебор доступен в прежнем API для сравнения.
- В EnforceRequiredGaps индекс КЭ ограничивает поиск локальной областью изменения.
  Явно назначенные IDs включаются даже вне рамки зоны; порядок КЭ сохраняется.
- До пересечения полигонов проверяется заведомое отсутствие пересечения габаритов.
  В предварительный габарит включены центроид и допуск для вырожденных КЭ.
- Повторный поиск ID в длинных списках заменён множествами в захвате покрытия рядов.
- В заголовке окна, версиях сборок и настройках установщика указана версия 1.3.
  Индикатор существующего UI-теста теперь записывает время перехода между этапами.

Бюджеты поиска, кандидаты, сортировки вариантов, точность геометрии, критерии As,
анкеровки, границ, зазоров, отверстий, продольных стыков и отката не изменены.

## Контроль на реальной плите

К2, Z=33,650 м, 12819 КЭ. В каждом запуске выбран один ряд; используются одни
и те же исходные JSON и настройки. Обе версии собраны Release x64, net48.
Настройки: B30, фон Ø8/200 сверху и снизу, GridCellMm=300,
MinZoneWidthM=0,3, DetailSlider=0, AveragePatchPeaks=false,
ApplySlabBoundaryAndOpeningRules=false (состояние сохранённых входных файлов).
Время измеряет PreviewRebuild.Regression от запуска пересчёта до независимой
диагностики и сохранения результата, без чтения исходного JSON и открытия окна.

- As4: **190,8 → 98,3 с** (−48,5%, примерно 1,94 раза), 112 зон.
- As2: **22,0 → 17,7 с** (−19,5%), 164 зоны.
- As1: **18,9 → 14,7 с** (−22,2%), 90 зон.

Это замеры на данном компьютере и этих входных данных, не гарантия такого же
ускорения на каждой плите. Первый дополнительный прогон прежней установленной
сборки As4 занял 192,9 с, первый прогон новой — 97,1 с.
Другие настройки и старые результаты из истории 1.2 напрямую с ними не сравниваются.

Для всех трёх рядов полный JSON обеих версий совпал после исключения только
CreatedUtc и нормализации случайных SpliceGroupId с сохранением состава групп.
Совпадают исходные КЭ/As, настройки, контуры, пятна, назначенные IDs, Ø, шаги,
длины, число стержней, типы семейств, загибы, привязки и диагностика. Непокрытых
КЭ и ошибок полной независимой диагностики нет. Расход стали не изменён.
UI продолжает обрабатывать Dispatcher; зум и ширина панелей сохраняются.

Повторяемые команды из каталога репозитория (Windows PowerShell 5.1):

```powershell
dotnet build 'Шаблон/src/LiraSlabZones.PreviewHost/LiraSlabZones.PreviewHost.csproj' `
  -c Release -p:Platform=x64 -p:GenerateSupportedRuntime=false -o <сборка>
powershell.exe -NoProfile -Sta -File 'Шаблон/tests/PreviewRebuild.Regression.ps1' `
  -BuildDirectory <сборка> -SourceJson <один_и_тот_же_вход.json> `

powershell.exe -NoProfile -File 'Шаблон/tests/CompareLayouts.Regression.ps1' `

  -CandidateJson <результат_1.3.json>
powershell.exe -NoProfile -File 'Шаблон/tests/ZoneCoverage.Prepared.Regression.ps1' `
  -BuildDirectory <сборка_1.3>
```

## Локальный запуск

Рядом с репозиторием, в `версия 1.3`, находятся `Программа` и ярлык
«Запуск LiraSlabZones 1.3 (предпросмотр зон)». В программе доступна кнопка
«Пересчитать зоны». `Программа/Открыть_As4.cmd` открывает готовый проверенный
результат. В `Программа/output` сохранены отдельные результаты As1/As2/As4.
Сборка Revit2025 лежит отдельно в `версия 1.3/Revit2025`.
Исходные JSON и локальные журналы сравнения не публикуются в Git.
Переносимый архив без рабочих данных: `releases/LiraSlabZones-1.3.0-Preview.zip`,
контрольная сумма — `releases/SHA256.txt`. Его можно воспроизвести командой
`powershell.exe -File Шаблон/tools/package-preview.ps1 -BuildDirectory <сборка>`.
Старые файлы `Шаблон/dist` относятся к предыдущим выпускам; общий установщик
Revit2022/2023/2025/2026 в этом выпуске не пересобирался.

Существующие нерешённые случаи As3 не исправлялись; полного контрольного прогона
As3 в этом выпуске нет. Геометрические тесты загибов не заменяют расчёт их
анкеровки по СП и проверку размещения семейств в живом Revit. Установленные
DLL и рабочие проекты Revit не обновлялись.
