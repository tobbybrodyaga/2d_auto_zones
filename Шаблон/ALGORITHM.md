# Алгоритм LiraSlabZones (автозоны доп. армирования)

Ориентир по смыслу: [SmartRebar / PromCore](https://promcore.io/blog/smartrebar/) — изополя As → прямоугольные зоны → подрезка контуром плиты → Revit.

## Единицы

| Что | Единицы |
|-----|---------|
| Координаты КЭ / контур / оси | **м** |
| Ø, шаг, длины SUM-3, анкеровка | **мм** |
| As, фон | **см²/м** |
| Футы | только в `ZonePlacer` при вставке в Revit |

## Пайплайн

```
ЛИРА (As1…As4 по КЭ)
    → фильтр уровня / горизонтальные плиты
    → контур плиты (граничные рёбра КЭ)
    → для каждого слоя As1…As4 (если включён):
         мозаика As−фон
         локальные пики
         рост пятна → зона
         клип краем плиты (−30 мм)
         зазор = шаг, без увода с пятна
    → превью / JSON / размещение SUM-30…34
```

## Шаг за шагом

### 1. Вход
- КЭ плиты с As1…As4, оси, (опц.) отверстия.
- Настройки: фон As, детализация (Max…Min), шаг 100/200, бетон B**, толщина.

### 2. Мозаика (`MosaicBuilder`)
- Регулярная сетка с шагом `GridCellMm` (по умолчанию 300).
- В ячейку: `max(As_layer − As_main)` по центроидам КЭ.
- Сглаживание одиночных пиков (`SmoothSingleSpike`).

### 3. Пики и рост пятна (`ZoneLayoutEngine`)
- Локальные максимумы мозаики.
- От сильного к слабому: порог `threshold × peak` (слайдер детализации).
- `GrowSolidRect`: расширяем прямоугольник, только если **вся** новая строка/столбец ≥ порога.

### 4. Геометрия зоны
- Длина вдоль стержней = пятно **+ 2×анкеровка** (у края плиты укоротится клипом).
- Ширина ⊥ стержням ≥ пятна, кратна шагу.
- Ø = минимальный, покрывающий As пика при шаге.
- Длина семейства из списка SUM-3 (`PickFamilyLength` / после клипа `PickFamilyLengthFit`).

### 5. Подрезка плитой (как SmartRebar)
- `MeshBoundary.ClipRectToSlab`: пересечение AABB зоны с inset-контуром (−30 мм).
- Центр зоны **обязан** быть внутри полигона контура; ≥2 угла внутри.
- Зона **не** «сдвигается наружу» с сохранением полной длины — лишнее обрезается.

### 6. Привязка к осям
- Сдвиг кратности **10 мм**, только если ось ≤ ~12 м от грани и сдвиг небольшой.
- Иначе зона «улетала» к чужим осям → оказывалась вне плиты.

### 7. Зазор между зонами
- Перпендикулярно длине стержней зазор = шаг (100/200 мм).
- Сдвиг ограничен; если уводит с пика/пятна — зона **отбрасывается**, а не кладётся «на пустое».

### 8. Покрытие пятна
- Ячейки мозаики помечаются «занятыми» **только после** успешной укладки.
- Раньше баг: клетка «съедалась» без зоны → открытое пятно изополей.

### 9. Проверка положения
После клипа/зазора зона должна:
- покрывать центр пика **или** ≥35% площади исходного пятна;
- лежать внутри контура плиты.

### 10. Превью
- Сетка КЭ + цвет As доп. по интервалам.
- Зоны полупрозрачные, цвет по Ø, подпись `Ø-длина` / `шаг`.
- Одна размерная цепочка сверху (все X + оси) и слева (все Y + оси).

### 11. Revit
- `ZonePlacer`: координаты м + offset/rotation UI → футы → семейства SUM-30…34.

## Где чаще всего ошибка (чеклист)

1. **Зоны вне плиты** — клип не сработал / оси утащили / зазор утащил. Смотри `ClipRectToSlab`, `AxisSnapper.maxSnapM`, `ResolvePerpGap`.
2. **Зоны на «белой» плите** — зона уехала с пика; должна отбрасываться проверкой `CoversPoint` / `OverlapsCore`.
3. **Открытое пятно As** — раньше: `assigned` до укладки. Теперь assign только при успехе.
4. **Несовпадение с Revit** — offset/поворот контура (как «Показать контур» в SmartRebar); единицы осей (м vs мм) — `NormalizeAxisUnits`.
5. **Фон слишком большой** — As−фон ≈ 0 → мозаика пустая, зон нет.

## Связь со SmartRebar

| SmartRebar | У нас |
|------------|--------|
| CSV узлы/элементы/арматура | COM ЛИРА → Core |
| Подрезка опалубкой/отверстиями | `ClipRectToSlab` + `HoleBentRules` |
| JSON → плагин Revit | JSON + `ZonePlacer` |
| Выравнивание контура с моделью | Offset X/Y, RotationDeg в UI |
